# 内置数据包

> 适用：Additional Abilities for DS `2.0.0` · Dragon Survival `≥ 2.0.68` · Wing Kirin `≥ 3.3.0`

本模组内置了**可选**数据包 —— 默认关闭，需要玩家手动启用。它们的作用是：用本模组的自定义技能组件
去重做别的模组（目前是 Wing Kirin）已有的技能。

---

## 一、现有内置包

| 包名 | 显示名 | 类型 | 作用 |
|---|---|---|---|
| `innovative_wingkirin_abilities` | 翼麒麟革新版技能 | 覆盖型数据包 | 用本模组的自定义组件重做 Wing Kirin 的部分技能 |

模组内全部内置包位于：

```
src/main/resources/data/additional_abilities/datapacks/
```

## 二、怎么启用

### 方式 A：数据包界面（推荐）

1. 新建世界时，或对已有世界走「编辑 → 数据包」；
2. 在左侧「可用」列表里找到**翼麒麟革新版技能**（名字后面带灰色的来源标注）；
3. 用箭头把它移到右侧「已选」列表，确认。

### 方式 B：指令

```
/datapack list                                     # 找到它的完整 id
/datapack enable "<id>"                            # 启用
/datapack disable "<id>"                           # 停用
```

包 id 由「模组 id + 包在资源里的路径」拼成，形如：

```
mod/additional_abilities:data/additional_abilities/datapacks/innovative_wingkirin_abilities
```

里面含 `:`，所以**必须用引号包住**。实际以 `/datapack list` 的输出为准。

### ⚠️ 两个必须知道的坑

**1. 千万不要用 `first`**

```
/datapack enable "<id>" first     ← 会让本包彻底失效，而且没有任何报错
```

已启用的数据包**越靠后优先级越高**。`first` 会把包插到列表**最前面**，等于最低优先级，
它的技能定义会被 Wing Kirin 的原版定义盖掉 —— 界面上显示「已启用」，
但游戏内技能数值**一点都没变**，日志里也**没有任何提示**。

用**不带后缀**的写法（等价于 `last`，插到末尾 = 最高优先级）就行。
确实需要精确控制位置时，可以用 `/datapack enable "<id>" after <某个包>`。

**2. 启用 / 停用后必须退出世界重新进入**

DS 的技能定义属于**数据包注册表**，只在**加载世界**时构建一次，`/reload` **不会**重建它们。
所以改完之后只跑 `/reload` 的话，会看到「数据包已启用，但技能一点没变」这种假象。
正确做法是退回标题界面，再重新进入世界。

## 三、各包的改动明细

### `innovative_wingkirin_abilities` 翼麒麟革新版技能

覆盖 Wing Kirin 的一些技能定义（路径 `data/wing_kirin/dragonsurvival/dragon_ability/`）。

#### 「孤注一掷」`wing_kirin:spell_binder`

| 项 | 原版 | 本包 |
|---|---|---|
| 激活类型 | `dragonsurvival:simple` | **`additional_abilities:charged`**（蓄力档位） |
| `cast_time` | 固定 `20` 刻 | `10 × 等级` 刻 |
| `charged_duration_per_level` | — | `10 × 等级` 刻 |
| `can_charge_exceed_cast_time` | — | `false`（蓄满即自动释放，不能超上限按住） |
| 施法期间的「点燃自己与队友」动作 | 有（`charging` 触发点，`ignite` 10 刻） | **已移除** |

> `cast_time` 与 `charged_duration_per_level` 取值相同；因为默认模式把蓄力上限前移 1 刻，
> 第 L 档的实际阈值是 `10 × 等级 - 1` 刻。换算规则见 [04-激活类型.md](04-激活类型.md)。

**玩法变化**：原版是按住读条 20 刻后释放；现在变成**蓄力档位** —— 蓄力时长决定实际生效等级，
**松手才释放**，蓄力不足第 1 档则取消施法。增益的持续时间与强度都按档位结算。
但要注意两条通用限制：档位不会超过玩家自身的技能升级等级，起手校验也仍按真实等级扣魔力。

#### 「龙吼功」`wing_kirin:thunderous_shout`

| 项 | 原版 | 本包 |
|---|---|---|
| 屏幕抖动 | 无 | 新增 `additional_abilities:simple_screen_vision`：`shake`，时长 `40 + 20 × (等级 - 1)` 刻，强度 `1 + 1 × (等级 - 1)`，必定生效 |

其余部分（伤害、虚弱、饥饿、引导结束时的力竭减益、动画、音效、升级方式）与原版完全一致。

---

#### 「安身法」`wing_kirin:fire_ring`

> 新增原创翼麒麟技能，灵感来自国产3A大作 **黑神话·悟空**。

综合利用了新增的*目标选择器*`additional_abilities:annulus`和`additional_abilities:domain`，是目前最好的技能示例。  
详细技能效果请在游戏实机内查看技能描述并亲身体验之，在此不展开。

#### 「一支穿云箭」`wing_kirin:signal_arrow`

| 项 | 原版 | 本包 |
|---|---|---|
| 方块发光 | 无 | 新增`additonal_abilities:glow`:`simple_shader`来增强提示范围 |

其余部分保持不变。

## 四、给附属模组作者：怎么再加一个内置包

1. 把包目录放进 `src/main/resources/`，例如 `src/main/resources/data/<modid>/datapacks/<包名>/`；
2. 目录根部**必须**有 `pack.mcmeta`（含 `pack.pack_format`）与 `pack.png`；
3. 在 `registry/PackFinders.java` 的 `addPackFinders` 里加一行调用，路径参数**必须**与真实目录完全一致；
4. 在 `lang/en_us.json` 与 `lang/zh_cn.json` 补上显示名语言键（`datapack.<modid>.<包名>`，描述键再加 `.desc`）；
5. 编译后进游戏，用 `/datapack list` 确认它出现。

选哪个注册方法看这张表：

| 包的类型 | 是否覆盖了别的模组已有的同名文件 | 用哪个方法 |
|---|---|---|
| 服务端数据包（`data/…`） | **是** | `addOverridingDataPack` |
| 服务端数据包（`data/…`） | 否 —— 只新增新 id / 新文件 | `addSimplePack` |
| 客户端资源包（`assets/…`） | 不适用（纯客户端使用） | `addSimplePack` |

**覆盖型必须用 `addOverridingDataPack`**：它刻意**不声明 KnownPack**。否则会出现
「服务端覆盖生效、客户端本地解析却拿到模组原版」的静默不一致 —— 现象同样是
「数据包已启用，但界面文案没变」，而服务端计算的部分（等级、效果时长、伤害、tag）却一切正常，
两者都不报错。原因与取舍写在 `PackFinders` 的类注释里。
纯新增型包没有这个问题，用简便 API 还能保留传输优化。

> 两个参数细节：`alwaysActive` 保持 `false` 才是「可选包」；位置保持 `Pack.Position.TOP`
> 才能排到已启用列表末尾、拥有覆盖 `mod_data` 的优先级。
