# 目标选择器（target_type）

> 适用：Additional Abilities for DS `2.0.0` · Dragon Survival `≥ 2.0.68`
> 相关：`actions[].target_selection.target_type`

目标选择器决定「这次技能选中谁」，写在 `actions[].target_selection` 里，
`target_type` 与 `applied_effects` **平级**：

```jsonc
"target_selection": {
  "target_type": "additional_abilities:xxx",
  "applied_effects": { /* 选中后做什么 */ },
  /* ← 该目标类型自己的字段也写在这一层 */
}
```

---

## 本模组新增的目标选择器

| `target_type` | 一句话 | 同源的内置类型 |
|---|---|---|
| `additional_abilities:anti_dragon_breath` | 龙息锥形，但朝施法者**身后**延伸 | `dragonsurvival:dragon_breath` |
| `additional_abilities:annulus` | 环形 —— 圆盘挖空内圈 | `dragonsurvival:disc` |
| `additional_abilities:domain` | **领域** —— 在施法处留下一块持续存在的区域，按间隔反复作用 | 无（DS 全部目标类型都是一次性的） |

---

## 一、`additional_abilities:anti_dragon_breath` 反向龙息锥形

**一句话**：与 DS 内置的 `dragonsurvival:dragon_breath` **完全一样**，只是锥体朝施法者**身后**延伸。

### 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `applied_effects` | 对象 | ✅ | — | 与 DS 所有目标选择器通用：写 `entity_effect[]` 或 `block_effect[]`，外加 `target_conditions` / `targeting_mode` / `is_harmful` |
| `range_multiplier` | 等级数值 | ✅ | — | 与施法者的 `dragonsurvival:dragon_breath_range` 属性**相乘**得到实际射程 |

字段与 `dragonsurvival:dragon_breath` 逐字相同。**把 `target_type` 换掉，就能把任意一个龙息技能改成"朝后喷"。**

### 示例

```json
{
  "target_selection": {
    "target_type": "additional_abilities:anti_dragon_breath",
    "range_multiplier": 1.0,
    "applied_effects": {
      "entity_effect": [
        {
          "effect_type": "dragonsurvival:potion",
          "potion": {
            "amplifier": 0.0,
            "duration": 60.0,
            "effects": "minecraft:glowing",
            "probability": 1.0
          }
        }
      ],
      "targeting_mode": "non_allies"
    }
  },
  "trigger_rate": 10.0
}
```

### 选箱体长什么样

以「眼高 1.62、体型 1、射程 4、水平朝 +X」为例：

| 目标类型 | X 区间 | Y 区间 | Z 区间 |
|---|---|---|---|
| `dragonsurvival:dragon_breath` | -1 ~ 4 | 0.81 ~ 2.43 | -1 ~ 1 |
| `additional_abilities:anti_dragon_breath` | **-4 ~ 1** | 0.81 ~ 2.43 | -1 ~ 1 |

前后反向、左右反向，**垂直方向不整体下移**（身体厚度那一份仍留在身体一侧）。

### 用法要点

- **开关只有 `target_type` 一处**。技能其余部分（音效、动画、`trigger_rate`、`applied_effects`）
  不用为「反向」做任何改动。
- **方块分支的朝向参数与 DS 龙息一致**，未做反向：传给方块效果的 `direction` 是
  「按眼睛世界坐标取最近轴向」，与视线朝哪无关。如果你的方块效果依赖这个朝向，注意这一点。
- **谁能被打由 `applied_effects.targeting_mode` 决定**，与目标类型本身无关。
  想只打敌人写 `non_allies` 或 `enemies`；想给自己人上 buff 写 `allies_and_self`。
- 侧边栏技能描述的文案本模组已带中文：
  - 方块分支 → `影响身后 %s 格锥形范围内的方块`
  - 实体分支 → `影响身后 %s 格锥形范围内的%s`

> 可运行的参考：`data/additional_abilities/dragonsurvival/dragon_ability/test_anti_dragon_breath.json`
> （命中的实体发光、箱体内浮白色粒子，便于肉眼确认范围方向）。该测试技能未挂在任何龙种下，
> 需要用 `/dragon-ability add` 自行授予。

## 二、`additional_abilities:annulus` 环形

**一句话**：与 DS 内置的 `dragonsurvival:disc` 同源，但**把内圈挖空** ——
只选中「内半径 ~ 外半径」之间的那圈环带。

### 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `applied_effects` | 对象 | ✅ | — | 与 DS 所有目标选择器通用：写 `entity_effect[]` 或 `block_effect[]`，外加 `target_conditions` / `targeting_mode` / `is_harmful` |
| `inner_radius` | 等级数值 | ✅ | — | 内圈半径（格）。**这个范围以内的一切都不会被选中** |
| `width` | 等级数值 | ✅ | — | 环宽（格），**沿径向由内向外叠加** |
| `height` | 等级数值 | ❌ | `1` | 厚度（格） |
| `height_starts_below` | 布尔 | ❌ | `false` | `false` → Y 区间 `[y, y + height]`；`true` → `[y - 1, y + height - 1]` |

`inner_radius` / `width` / `height` 都支持 `LevelBasedValue` 的全部写法
（`linear` / `lookup` / 常数…），例如
`"width": { "type": "minecraft:linear", "base": 2.0, "per_level_above_first": 0.5 }`。

### 作用范围

```
origin = 施法者脚部位置（与 disc 一致）
r_in   = inner_radius
r_out  = inner_radius + width          ← 环宽沿径向叠加，不是外半径
包围盒（XZ） = origin ± r_out
Y 区间       = height_starts_below ? [y - 1, y + height - 1] : [y, y + height]
命中条件：水平距离 d 满足  r_in ≤ d ≤ r_out（闭区间）
```

### 示例

```json
{
  "target_selection": {
    "target_type": "additional_abilities:annulus",
    "inner_radius": 5,
    "width": 1.0,
    "height": 3.0,
    "height_starts_below": true,
    "applied_effects": {
      "entity_effect": [
        {
          "effect_type": "dragonsurvival:potion",
          "potion": { "amplifier": 0.0, "duration": 60.0, "effects": "minecraft:glowing", "probability": 1.0 }
        }
      ],
      "targeting_mode": "all"
    }
  },
  "trigger_rate": 10.0
}
```

上面这份配置选中「半径 5 ~ 6 格、且从脚下一格起算共 3 格厚」的一圈环带。

### 用法要点

- **命中的是环带，不是圆盘**。`inner_radius` 以内完全不受影响 —— 这正是它相对 `disc` 的价值所在
  （例如做「光环」只打外围，同时在脚下给自己留一块安全区）。
- **只比较水平距离**，Y 方向完全交给 `height` 与 `height_starts_below`。
  所以它是「环形 × 厚度」的**圆柱壳**，不是三维球壳 —— 这也是 `height` 能独立存在的语义基础。
- **遍历量不会因为内圈是空的而变小**。包围盒粗筛之后，仍要遍历
  `(2 × r_out + 1)² × 高度` 个方块位置。`inner_radius` 给大值时请同步抬高 `trigger_rate`
  （建议 ≥ 5），否则每刻的开销会明显上去。
- **边界判定用中心点法**：方块取格中心 `(x + 0.5, z + 0.5)`，实体取 `position()`（脚部中心）。
  判定可预测、易复现，不会出现「看起来多吃一格」的观感。
- **侧边栏描述保留 2 位小数**（DS 的 `disc` 是直接取整），所以小数半径不会被显示成整数。
  描述里的「范围」显示的是**外半径**（环带最远处）。
- **方块分支的 `direction` 传 `null`** —— 与 DS 的 `area` / `disc` 一致
  （只有 `looking_at` 会传真实命中面朝向）。依赖朝向的方块效果需要自行兜底。
- **F3+B 会画内外双框**：青色为外边界，暗青为内（挖空）边界。
  这对框由本模组单独绘制 —— DS 的 `ClientDragonRenderer#renderAbilityHitbox` 是硬编码分支链，
  没有扩展点。
- 谁能被打同样由 `applied_effects.targeting_mode` 决定，与目标类型本身无关。

> 可运行的参考：`data/additional_abilities/dragonsurvival/dragon_ability/test_annulus.json`
> （内半径 5 / 环宽 1 / 厚度 3 且从脚下一格起算；命中的实体发光并被龙息粒子包裹，
> 方块侧生成末地烛粒子并点燃）。该测试技能未挂在任何龙种下，
> 需要用 `/dragon-ability add` 自行授予。

## 三、`additional_abilities:domain` 领域

**一句话**：施法时在**施法处留下一块持续存在**的区域，按 `apply_interval` 反复对范围内的
实体 / 方块重放 `applied_effects`，`duration` 到期后消失。

### 它与 DS 全部内置目标类型的根本区别

内置的 5 种（`self` / `area` / `disc` / `looking_at` / `dragon_breath`）都是**一次性**的：
`apply` 被调用的那一瞬间选中目标、立刻执行效果，**之后什么都不留下**。
所以 DS 里做不出「在施法地留下一个维持一段时间的领域并产生持续作用」——
本类型就是补这个缺口，它是本模组唯一一个有**生命周期**的目标类型。

### 为什么做成目标类型

作用链是 `actions[] → target_selection → applied_effects`，而 `applied_effects`
（`Either<block_effect[], entity_effect[]>`）只存在于 `target_selection` 这一层。
**只有做成目标类型才能原样复用这个字段**，从而让 DS 的**全部 33 种实体效果与全部方块效果**
（`modifier` / `potion` / `run_function` / `damage` / `summon_entity` / `particle` / `fire` /
`conversion` / `extinguish` …）零适配可用，且上游新增效果自动生效。
做成激活类型拿不到 `applied_effects`，只能把效果字段整套重定义一遍。

### 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `applied_effects` | 对象 | ✅ | — | 与 DS 所有目标选择器通用：写 `entity_effect[]` 或 `block_effect[]`，外加 `target_conditions` / `targeting_mode` / `is_harmful` |
| `radius` | 等级数值 | ✅ | — | 半径（格）。**球形 / 方形** = 每轴半边长；**柱形** = 水平半径 |
| `duration` | 等级数值 | ✅ | — | 领域存活 tick（20 = 1 秒） |
| `shape` | 枚举 | ❌ | `sphere` | `sphere` / `cube` / `cylinder` |
| `height` | 等级数值 | ❌ | = `radius` | 仅柱形：从锚点**向上额外延伸**的格数 |
| `height_starts_below` | 布尔 | ❌ | `false` | 仅柱形：`false` → Y 区间 `[y, y + height]`；`true` → `[y - 1, y + height - 1]` |
| `apply_interval` | 等级数值 | ❌ | `20` | 每 N tick 结算一次 |
| `anchor` | 枚举 | ❌ | `casting_position` | `casting_position`（施法位置，**永久固定**）/ `caster`（跟随施法者） |
| `max_domains` | 整数 | ❌ | `1` | 同一技能**同时存在几次施法的领域**的上限，超出时顶掉最旧的 |
| `remove_effects_on_end` | 布尔 | ❌ | `false` | 消散前对范围内目标调一次 `remove`（见用法要点） |

`radius` / `duration` / `height` / `apply_interval` 都支持 `LevelBasedValue` 的全部写法
（`linear` / `lookup` / 常数…）。

### 作用范围

```
origin = 锚点（casting_position 时 = 首次结算瞬间的施法者脚部位置）

sphere   : 包围盒 = origin ± radius（三轴等长），再按三维距离 ≤ radius 精筛（切掉包围盒的 8 个角）
cube     : 包围盒 = origin ± radius，无精筛（与内部 area 的立方语义一致）
cylinder : 包围盒 = XZ origin ± radius，Y 区间同 disc / annulus
           height_starts_below=false → [y, y + height]（共 height+1 格）
           height_starts_below=true  → [y - 1, y + height - 1]
           精筛：水平距离 ≤ radius（切掉水平四角）
```

三种形状的 `radius` 含义统一为「半边长」，所以切换形状时不会出现范围错觉。
取点口径与其它目标类型一致：**方块取格中心** `(x+0.5, y+0.5, z+0.5)`，
**实体取 `position()`**（脚部中心）。

### 时间线

```
读条完成那一帧（currentTick == cast_time）
 ├─ 建立领域：锚点取此刻 dragon.position()，参数（半径 / 形状 / 间隔 / 时长 / 效果集）全部固化
 ├─ 立刻结算一次 —— 效果即时生效，不用等第一个 apply_interval
 └─ simple 随即自动 stopCasting，施法者立刻可以自由行动
此后每 apply_interval tick 结算一次
duration 到期 → 领域消散（remove_effects_on_end: true 时先对范围内目标调 remove）
```

### 示例一：`simple` 主动释放（主用法）

```json
{
  "actions": [
    {
      "target_selection": {
        "target_type": "additional_abilities:domain",
        "radius": { "type": "minecraft:linear", "base": 4.0, "per_level_above_first": 1.0 },
        "duration": { "type": "minecraft:linear", "base": 200.0, "per_level_above_first": 100.0 },
        "apply_interval": 20.0,
        "shape": "sphere",
        "anchor": "casting_position",
        "applied_effects": {
          "entity_effect": [
            {
              "effect_type": "dragonsurvival:potion",
              "potion": { "amplifier": 0.0, "duration": 60.0, "effects": "minecraft:regeneration", "probability": 1.0 }
            }
          ],
          "targeting_mode": "allies_and_self"
        }
      }
    }
  ],
  "activation": {
    "activation_type": "dragonsurvival:simple",
    "cast_time": 20.0,
    "cooldown": 400.0,
    "initial_mana_cost": 3.0
  }
}
```

### 示例二：`channeled` 引导维持

把上面的 `activation` 换成引导即可，领域语义变为「**引导期间维持，松手之后再看 `duration` 的余韵**」：

```json
"activation": {
  "activation_type": "dragonsurvival:channeled",
  "cast_time": 20.0,
  "max_duration": 200.0,
  "cooldown": 400.0,
  "initial_mana_cost": 3.0,
  "continuous_mana_cost": { "type": "ticking", "amount": 0.02 }
}
```

`channeled` 会每 `trigger_rate` tick 调一次本类型，而这些调用会被识别为**同一次施法**，
只做「续命 + 并入效果」——**不换锚点、不重置结算节拍**。所以：

- 锚点固定在**引导正式开始那一帧**的位置，引导期间不会跟着你迁移；
- 效果结算严格按 `apply_interval` 进行，与 `trigger_rate` 解耦（**两级节流**）；
- 松手 / 断魔 / 到达 `max_duration` 之后，领域还会按 `duration` 继续存活一段时间再消散；
- 期间又在新位置重新引导，则会判定为**新一次施法**：旧领域收尾，新领域落在新位置。

### 一次施法 = 一个领域（多 action 会合并）

`applied_effects` 是 `Either` —— **同一个 `target_selection` 装不下实体效果和方块效果**。
要「一个领域既影响实体又影响方块」，只能写两个都指向本类型的 `target_selection`。
这两个 action 共享同一次施法，于是第二个会**并入**第一个的领域：
**一个领域、一份锚点与计时、两组效果**，而不是各建一个互相顶替。

> 合并时**形状 / 半径 / 时长 / 间隔以第一个 action 为准**，后续 action 只贡献 `applied_effects`。
> 建议把多个 domain action 的这些参数写成一致，避免误读。

### 用法要点

- ⚠️ **`cast_time` 必须 ≥ 1**（`simple` 下）。DS 的 `ActionContainer#tick` 用
  `actualTick = currentTick - cast_time` 做节流；若 `cast_time = 0`，首次结算的 `actualTick = 1`，
  此时只要 `trigger_rate > 1` 就会 `1 % rate != 0`，**`apply` 永不执行、领域根本不会生成**。
  （`channeled` 下同样的配置只是把首次结算推迟到第 `trigger_rate` tick，不会永不触发。）
- **不持久化**：领域只活在内存里，服务端重启即消失。这是有意的——把 DS 的效果配置序列化进存档
  会随 DS 版本变动而脆断，而领域生命周期本身只有几十秒到几分钟。
- **施法者离线或换了维度时**：跳过结算，但计时照走。既不会崩，也不会出现「施法者回来时领域才继续」
  的隐式暂停。
- **`should_remove_automatically` 口径不同**：DS 各类持续效果的这个开关判的是
  「目标与**施法者**的距离 > `getDistance()`」，而本类型锚点通常固定在施法位置。
  想要「离开领域即失效」请用 `remove_effects_on_end: true`。
- **方块分支的遍历量**：`cube` / `sphere` 的包围盒是 `(2r+1)³` 个位置，球形精筛后约剩一半。
  `radius` 给大值时请同步抬高 `apply_interval`（默认 20 已经比较保守；不建议低于 10）。
  实体分支不受影响（一次 AABB 查询）。
- **方块分支的 `direction` 传 `null`** —— 与 DS 的 `area` / `disc` 一致（领域锚点没有"命中面"概念）。
- **谁能被影响**由 `applied_effects.targeting_mode` 决定，与目标类型本身无关（同 DS 其它目标类型）。
- **视觉**：本类型不做专属渲染。领域内的可见表现交给技能自带的 `particle` 效果 ——
  因为它每 `apply_interval` 都会被重放，天然形成「持续粒子」。
- **F3+B 会画一个橙色框**：以玩家当前脚下为锚点，表示「现在施法会留下多大的领域」。
  球会切掉包围盒的 8 个角、柱形会切掉水平四角，所以线框比真实判定区略大，属预期。

> 可运行的参考：`data/additional_abilities/dragonsurvival/dragon_ability/test_domain.json`
> （球形 / 半径 4 / 持续 200 tick / 每 20 tick 结算；实体侧给盟友与自己生命恢复 + 龙息粒子，
> 方块侧撒末地烛粒子 —— 这条同时是「多 action 合并」的活例）。
> 该测试技能未挂在任何龙种下，需要用 `/dragon-ability add` 自行授予。
