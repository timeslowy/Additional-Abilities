# 目标选择器（target_type）

> 适用：Additional Abilities for DS `2.0.0` · Dragon Survival `≥ 2.0.68`
> 相关：`actions[].target_selection.target_type`

目标选择器决定「这次技能选中谁」，写在 `actions[].target_selection` 里，
`target_type` 与 `applied_effects` **平级**：

```jsonc
"target_selection": {
  "target_type": "additional_abilities:xxx",
  "applied_effects": { /* 选中后做什么 */ },
  /* ← 该目标类型自己的字段也写在这一层 */
}
```

---

## 本模组新增的目标选择器

| `target_type` | 一句话 | 同源的内置类型 |
|---|---|---|
| `additional_abilities:anti_dragon_breath` | 龙息锥形，但朝施法者**身后**延伸 | `dragonsurvival:dragon_breath` |
| `additional_abilities:annulus` | 环形 —— 圆盘挖空内圈 | `dragonsurvival:disc` |

---

## 一、`additional_abilities:anti_dragon_breath` 反向龙息锥形

**一句话**：与 DS 内置的 `dragonsurvival:dragon_breath` **完全一样**，只是锥体朝施法者**身后**延伸。

### 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `applied_effects` | 对象 | ✅ | — | 与 DS 所有目标选择器通用：写 `entity_effect[]` 或 `block_effect[]`，外加 `target_conditions` / `targeting_mode` / `is_harmful` |
| `range_multiplier` | 等级数值 | ✅ | — | 与施法者的 `dragonsurvival:dragon_breath_range` 属性**相乘**得到实际射程 |

字段与 `dragonsurvival:dragon_breath` 逐字相同。**把 `target_type` 换掉，就能把任意一个龙息技能改成"朝后喷"。**

### 示例

```json
{
  "target_selection": {
    "target_type": "additional_abilities:anti_dragon_breath",
    "range_multiplier": 1.0,
    "applied_effects": {
      "entity_effect": [
        {
          "effect_type": "dragonsurvival:potion",
          "potion": {
            "amplifier": 0.0,
            "duration": 60.0,
            "effects": "minecraft:glowing",
            "probability": 1.0
          }
        }
      ],
      "targeting_mode": "non_allies"
    }
  },
  "trigger_rate": 10.0
}
```

### 选箱体长什么样

以「眼高 1.62、体型 1、射程 4、水平朝 +X」为例：

| 目标类型 | X 区间 | Y 区间 | Z 区间 |
|---|---|---|---|
| `dragonsurvival:dragon_breath` | -1 ~ 4 | 0.81 ~ 2.43 | -1 ~ 1 |
| `additional_abilities:anti_dragon_breath` | **-4 ~ 1** | 0.81 ~ 2.43 | -1 ~ 1 |

前后反向、左右反向，**垂直方向不整体下移**（身体厚度那一份仍留在身体一侧）。

### 用法要点

- **开关只有 `target_type` 一处**。技能其余部分（音效、动画、`trigger_rate`、`applied_effects`）
  不用为「反向」做任何改动。
- **方块分支的朝向参数与 DS 龙息一致**，未做反向：传给方块效果的 `direction` 是
  「按眼睛世界坐标取最近轴向」，与视线朝哪无关。如果你的方块效果依赖这个朝向，注意这一点。
- **谁能被打由 `applied_effects.targeting_mode` 决定**，与目标类型本身无关。
  想只打敌人写 `non_allies` 或 `enemies`；想给自己人上 buff 写 `allies_and_self`。
- 侧边栏技能描述的文案本模组已带中文：
  - 方块分支 → `影响身后 %s 格锥形范围内的方块`
  - 实体分支 → `影响身后 %s 格锥形范围内的%s`

> 可运行的参考：`data/additional_abilities/dragonsurvival/dragon_ability/test_anti_dragon_breath.json`
> （命中的实体发光、箱体内浮白色粒子，便于肉眼确认范围方向）。该测试技能未挂在任何龙种下，
> 需要用 `/dragon-ability add` 自行授予。

## 二、`additional_abilities:annulus` 环形

**一句话**：与 DS 内置的 `dragonsurvival:disc` 同源，但**把内圈挖空** ——
只选中「内半径 ~ 外半径」之间的那圈环带。

### 字段

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `applied_effects` | 对象 | ✅ | — | 与 DS 所有目标选择器通用：写 `entity_effect[]` 或 `block_effect[]`，外加 `target_conditions` / `targeting_mode` / `is_harmful` |
| `inner_radius` | 等级数值 | ✅ | — | 内圈半径（格）。**这个范围以内的一切都不会被选中** |
| `width` | 等级数值 | ✅ | — | 环宽（格），**沿径向由内向外叠加** |
| `height` | 等级数值 | ❌ | `1` | 厚度（格） |
| `height_starts_below` | 布尔 | ❌ | `false` | `false` → Y 区间 `[y, y + height]`；`true` → `[y - 1, y + height - 1]` |

`inner_radius` / `width` / `height` 都支持 `LevelBasedValue` 的全部写法
（`linear` / `lookup` / 常数…），例如
`"width": { "type": "minecraft:linear", "base": 2.0, "per_level_above_first": 0.5 }`。

### 作用范围

```
origin = 施法者脚部位置（与 disc 一致）
r_in   = inner_radius
r_out  = inner_radius + width          ← 环宽沿径向叠加，不是外半径
包围盒（XZ） = origin ± r_out
Y 区间       = height_starts_below ? [y - 1, y + height - 1] : [y, y + height]
命中条件：水平距离 d 满足  r_in ≤ d ≤ r_out（闭区间）
```

### 示例

```json
{
  "target_selection": {
    "target_type": "additional_abilities:annulus",
    "inner_radius": 5,
    "width": 1.0,
    "height": 3.0,
    "height_starts_below": true,
    "applied_effects": {
      "entity_effect": [
        {
          "effect_type": "dragonsurvival:potion",
          "potion": { "amplifier": 0.0, "duration": 60.0, "effects": "minecraft:glowing", "probability": 1.0 }
        }
      ],
      "targeting_mode": "all"
    }
  },
  "trigger_rate": 10.0
}
```

上面这份配置选中「半径 5 ~ 6 格、且从脚下一格起算共 3 格厚」的一圈环带。

### 用法要点

- **命中的是环带，不是圆盘**。`inner_radius` 以内完全不受影响 —— 这正是它相对 `disc` 的价值所在
  （例如做「光环」只打外围，同时在脚下给自己留一块安全区）。
- **只比较水平距离**，Y 方向完全交给 `height` 与 `height_starts_below`。
  所以它是「环形 × 厚度」的**圆柱壳**，不是三维球壳 —— 这也是 `height` 能独立存在的语义基础。
- **遍历量不会因为内圈是空的而变小**。包围盒粗筛之后，仍要遍历
  `(2 × r_out + 1)² × 高度` 个方块位置。`inner_radius` 给大值时请同步抬高 `trigger_rate`
  （建议 ≥ 5），否则每刻的开销会明显上去。
- **边界判定用中心点法**：方块取格中心 `(x + 0.5, z + 0.5)`，实体取 `position()`（脚部中心）。
  判定可预测、易复现，不会出现「看起来多吃一格」的观感。
- **侧边栏描述保留 2 位小数**（DS 的 `disc` 是直接取整），所以小数半径不会被显示成整数。
  描述里的「范围」显示的是**外半径**（环带最远处）。
- **方块分支的 `direction` 传 `null`** —— 与 DS 的 `area` / `disc` 一致
  （只有 `looking_at` 会传真实命中面朝向）。依赖朝向的方块效果需要自行兜底。
- **F3+B 会画内外双框**：青色为外边界，暗青为内（挖空）边界。
  这对框由本模组单独绘制 —— DS 的 `ClientDragonRenderer#renderAbilityHitbox` 是硬编码分支链，
  没有扩展点。
- 谁能被打同样由 `applied_effects.targeting_mode` 决定，与目标类型本身无关。

> 可运行的参考：`data/additional_abilities/dragonsurvival/dragon_ability/test_annulus.json`
> （内半径 5 / 环宽 1 / 厚度 3 且从脚下一格起算；命中的实体发光并被龙息粒子包裹，
> 方块侧生成末地烛粒子并点燃）。该测试技能未挂在任何龙种下，
> 需要用 `/dragon-ability add` 自行授予。
