# 本模组随附的技能一览

> 适用：Additional Abilities for DS `2.0.0`
> 前置：Dragon Survival `≥ 2.0.68` · （可选）Wing Kirin `≥ 3.3.0`

> 另外，本模组还内置了一个**可选数据包**，用本模组的自定义组件重做了 Wing Kirin 的部分技能。它**默认不启用**，改动明细与启用方法见 [07-内置数据包.md](07-内置数据包.md)。

> 另有一批 `test_*` 测试技能（`test_charged` / `test_charged_hold` / `test_optional_charged` /
> `test_block_quake` / `test_glow` / `test_screen_vision` / `test_enchantment_bonus` / `test_durability` /
> `test_anti_dragon_breath` / `test_annulus` / `test_domain` /
> `test_on_block_placed` / `test_on_item_consumed` / `test_on_ability_cast`），
> 仅供开发调试，**未挂在任何龙种下**，需要用指令自行授予。
> 各测试技能对应的自定义类型见 [README](../../README.md) 速查表。  
> ***tips：因调试所需，测试技能实际并非完全与技能描述相符，以实际为准。***

## 总览

| 技能 id | 名称 | 所属龙种 | 激活方式 | 最高等级 | 解锁 / 升级 |
|---|---|---|---|---|---|
| `sea_dragon:extinguish_breath` | 止火之息 | 海龙| `channeled` 持续吐息 | 4 | 经验等级 `0 / 10 / 20 / 40` |
| `cave_dragon:smoke_breath` | 障目之息 | 洞穴龙 | `channeled` 持续吐息 | 3 | 经验等级 `0 / 10 / 20` |

| `forest_dragon:natural_alies` | 草木皆兵 | 森林龙 | `simple` 读条 | 4 | 成长值 `30 / 40 / 50 / 60`（升级类型 `dragon_growth`） |

各技能的显示名 / 描述文案语言键：

```
dragon_ability.<命名空间>.<技能id>          → 名称
dragon_ability.<命名空间>.<技能id>.desc     → 技能描述
```

## 止火之息 `extinguish_breath`

> 「喷吐大量水汽，浇灭所及之处的火焰，亦包括失火的生物。」
> 「射程取决于年龄，抗火时间则取决于经验等级。」「无法在熔岩里使用。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:channeled`，`cast_time` 30 刻，冷却 60 刻 |
| 持续耗蓝 | 每刻 `0.02` |
| 使用限制 | **眼睛处于熔岩中时禁用** |

**效果**：锥形吐息，一共 4 段动作：

1. 对锥形范围内**所有**生物施加**抗火**，时长 200 × 档位 刻（10 / 20 / 30 / 40 秒）；
2. 打掉范围内的 `minecraft:fire` 与 `minecraft:soul_fire`；
3. 把**营火 / 灵魂营火**转成未点燃状态（各 50% 概率），并留下一团水汽云
   （80 刻，云中 50% 概率补 600 刻抗火）；
4. 自身播放呼吸粒子（水泡粒子）。

**用法提示**：这是**辅助 / 灭火**技能，几乎不造成伤害。给队友和自己灭身上的火、清一片火场用它。

## 障目之息 `smoke_breath`

> 「喷吐大量烟气，蒙蔽敌人的双眼。」
> 「射程取决于年龄，施加的失明时间则取决于经验等级。」「也有些许伤害，但远远低于炽焰之息。」
> 「无法在水下或雨间使用。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:channeled`，`cast_time` 5 刻，冷却 20 刻 |
| 持续耗蓝 | 每刻 `0.02` |
| 使用限制 | **眼睛在水中时禁用**；**下雨 / 下雪时禁用** |

**效果**：锥形吐息，3 段动作：

1. 对锥形内的敌人造成火焰伤害（`0.5 × 档位`）并施加**失明 200 刻（10 秒）**；
2. 自身播放烟气呼吸粒子；
3. 留下烟气云（40 刻，云中 10% 概率施加 600 刻失明）。

**用法提示**：起手极快（`cast_time` 5 刻），是贴脸打断 + 致盲的短冷却手段。敌人被失明后退开就是收益。

## 火眼金睛 `piercing_eye`

> 「在熔岩里的生活使你练就了一双火眼金睛，让目光能穿过迷雾（免疫失明）。」
> 「当然，此效果不能免疫黑暗。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:passive` 被动 |
| 等级 | 无 `upgrade` 配置 → 固定 1 级，不能升级 |
| 效果 | 将 `minecraft:blindness` 的持续时间 **× 0**，即完全免疫失明 |

**用法提示**：**只免疫失明，不免疫黑暗**（Darkness）。洞穴龙的常驻被动之一。

## 草木皆兵 `natural_alies`

> 「你与自然共生共处、交感相融，竟拥有了让一草一木传递攻势的魔力。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:simple`，`cast_time` 40 刻，初始耗蓝 6 |
| 冷却 | 每级 `600 / 800 / 1000 / 1200` 刻（30 / 40 / 50 / 60 秒；线性 `base` 600、每级 +200） |
| 蓄力期间可移动 | 否（读条期间锁颈锁尾，动画 `cast_mass_buff` → `mass_buff`） |
| 使用限制 | **必须站在草木系方块上才能放**（`#dragonsurvival:speeds_up_forest_dragon`） |
| 等级 | 最高 4 级，`dragonsurvival:dragon_growth` 成长升级：成长值 `30 / 40 / 50 / 60` → 1 / 2 / 3 / 4 级（超出用 fallback `10`） |
| 定位 | 半径 8，`dragonsurvival:area` 范围选择器 |

**效果**：三段动作。

1. **蓄力预告**（`trigger_point` = `charging`，`trigger_rate` 10）：
   读条期间**每 10 刻**把半径 8 格内、属于 `#dragonsurvival:speeds_up_forest_dragon` 的**非空气方块**
   染上本模组的 `additional_abilities:glow` —— 绿色 `#0cb97f`、`alpha` 0.5、`display_type` = `simple_shader`，
   单次 40 刻。一草一木先亮起来，也是在给对方「倒计时」。
2. **结算**（读条完成时执行一次，即默认 `trigger_point`）：
   对半径 8 格内**所有非友方生物**（`targeting_mode` = `non_allies`）中
   **正踩在草木系方块上**的个体（`target_conditions` → `entity_properties.predicate.stepping_on`）——
   - 造成 `forest_dragon:natural_force`（自然之力）伤害，数值 = **目标最大生命值 × `0.05 × 技能等级`**
     （5 / 10 / 15 / 20%），再按默认表达式乘上施法者的「龙之技能伤害」属性；
   - 施加**缓慢 II + 虚弱 II**（`amplifier` 1），时长 `100 / 160 / 220 / 280` 刻（5 / 8 / 11 / 14 秒）；
   - 追加一条**隐藏的**伤害修正 `forest_dragon:natural_damage_increase`：对
     `#forest_dragon:is_forest_dragon`（森林龙法术）的**受伤倍率 ×2**，时长同上 —— 即描述里的「更易为森林龙法术所伤」。
3. **表现**：半径 8 格内的非空气方块上迸出 5 颗 `minecraft:egg_crack` 粒子。

**用法提示**：这是一发**「地形绑定」的范围减益**，判定挂在**目标脚下**的方块上，而**自己脚下**只决定
「能不能放得出来」（`usage_blocked`）。所以正确用法是：先把敌人拖到草皮、泥土、腐殖土、原木或木板地面上
（`#dragonsurvival:speeds_up_forest_dragon` = `#minecraft:dirt` + `#minecraft:logs` + `#minecraft:planks` +
`#minecraft:wooden_slabs` + `#dragonsurvival:is_grassy` + 草方块），再施法 —— 石头、沙子、水面、半空中
**一点伤害都吃不到**。给目标挂上 ×2 易伤后再补一口龙息，是这套连招的收益点。

> 随技能一并新增的还有伤害类型 `forest_dragon:natural_force`
> （`data/forest_dragon/damage_type/natural_force.json`）与龙种伤害标签
> `#forest_dragon:is_forest_dragon`（`data/forest_dragon/tags/damage_type/is_forest_dragon.json`，
> 内含 `dragonsurvival:forest_breath` / `dragonsurvival:spike` / 本伤害类型），
> 以及死亡留言键 `death.attack.forest_dragon.natural_force`。

## 三连箭雷 `explosion_arrow`

> 「完成『见鬼去吧』挑战进度以解锁。」
> 「捂好耳朵，要打雷了！」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:simple`，`cast_time` 20 刻，冷却 300 刻，初始耗蓝 5 |
| 蓄力期间可移动 | 是 |
| 解锁 | 升级类型 `condition_based`，条件 = 拥有进度 `nether/return_to_sender`（「见鬼去吧」） |

**效果**：朝视线方向一次射出 **3 支箭雷**（速度 2、散布 4°）。
箭雷命中后爆炸，爆炸的伤害 / 范围 / 音效等参数由 Wing Kirin 侧的数据
（`wing_kirin:dragonsurvival/projectile_data/explosion_arrow*` 与对应函数）驱动。

**用法提示**：长冷却（15 秒）、偏高耗蓝，作为一次爆发使用。解锁需要完成进度「见鬼去吧」（把下界恶魂的火球打回去）。

## 无所遁形 `entity_marker`

> 「完成『眼前一亮！』进度以解锁。」
> 「发现敌人位置！（标记敌人 +10 分）」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:passive` + 触发器 `dragonsurvival:on_key_pressed`，键位为**鼠标左键** |
| 等级 | 最高 2 级，`experience_points` 经验点升级（`50 / 100 / 200`，超出用 fallback `100`） |
| 解锁 | 需**已是翼麒麟**，且已获得进度 `husbandry/make_a_sign_glow`（「眼前一亮！」） |
| 定位 | 射程 200，`looking_at` 目标，`all_except_self` |

**效果**：按左键标记**视线正对着的那个生物**，使其发光（光源 id `wing_kirin:looking_at_marker`，
颜色 `#d80835` 红色），时长 400 × 档位 刻（20 / 40 秒）。

**用法提示**：这是「标记」类技能 —— 让点指到的敌人显形，而使其无法隐蔽。
**只标记单个目标**（视线命中的那一个），不是范围扫描。可以在技能界面手动禁用。

## 怎么把技能发给玩家

技能默认按上表的龙种标签发放。测试 / 手动授予用 DS 自带的指令：

```
/dragon-ability add <目标> <技能id>        # 授予
/dragon-ability remove <目标> <技能id>     # 移除
/dragon-ability refresh [<目标>]           # 刷新技能数据
```

龙种标签文件位置：

```
data/dragonsurvival/tags/dragonsurvival/dragon_ability/<龙种>.json
```

本模组对这些标签是**追加**（`"replace": false`），不会覆盖原版龙种的技能表。
