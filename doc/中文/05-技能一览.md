# 本模组随附的技能一览

> 适用：Additional Abilities for DS `2.0.0`
> 前置：Dragon Survival `≥ 2.0.68` · （可选）Wing Kirin `≥ 3.3.0`

> 另外，本模组还内置了一个**可选数据包**，用本模组的自定义组件重做了 Wing Kirin 的部分技能。它**默认不启用**，改动明细与启用方法见 [07-内置数据包.md](07-内置数据包.md)。

> 另有一批 `test_*` 测试技能（`test_charged` / `test_charged_hold` / `test_optional_charged` /
> `test_block_quake` / `test_glow` / `test_screen_vision` / `test_enchantment_bonus` / `test_durability` /
> `test_anti_dragon_breath` / `test_annulus` / `test_domain` /
> `test_on_block_placed` / `test_on_item_consumed` / `test_on_ability_cast`），
> 仅供开发调试，**未挂在任何龙种下**，需要用指令自行授予。
> 各测试技能对应的自定义类型见 [README](../../README.md) 速查表。  
> ***tips：因调试所需，测试技能实际并非完全与技能描述相符，以实际为准。***

> **为什么「安身法」的 id 在 `wing_kirin:` 命名空间下？** 它是本模组的**原创**技能，但图标贴图用的是
> Wing Kirin 的 `wing_kirin:abilities/fire_ring/*`（本模组不打任何 Wing Kirin 的素材进 jar），
> 且 `usage_blocked` 直接判定龙种 `dragonsurvival:wing_kirin`，故沿用该命名空间。
> 它**随 jar 常驻生效**，不需要启用任何数据包；在检测到未安装 Wing Kirin 时会被
> `neoforge:conditions` 自动跳过，**不会导致世界加载失败**。

各技能的显示名 / 描述文案语言键：

```
dragon_ability.<命名空间>.<技能id>          → 名称
dragon_ability.<命名空间>.<技能id>.desc     → 技能描述
```

## 止火之息 `extinguish_breath`

> 「喷吐大量水汽，浇灭所及之处的火焰，亦包括失火的生物。」
> 「射程取决于年龄，抗火时间则取决于经验等级。」「无法在熔岩里使用。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:channeled`，`cast_time` 30 刻，冷却 60 刻 |
| 持续耗蓝 | 每刻 `0.02` |
| 使用限制 | **眼睛处于熔岩中时禁用** |

**效果**：锥形吐息，一共 4 段动作：

1. 对锥形范围内**所有**生物施加**抗火**，时长 200 × 档位 刻（10 / 20 / 30 / 40 秒）；
2. 打掉范围内的 `minecraft:fire` 与 `minecraft:soul_fire`；
3. 把**营火 / 灵魂营火**转成未点燃状态（各 50% 概率），并留下一团水汽云
   （80 刻，云中 50% 概率补 600 刻抗火）；
4. 自身播放呼吸粒子（水泡粒子）。

**用法提示**：这是**辅助 / 灭火**技能，几乎不造成伤害。给队友和自己灭身上的火、清一片火场用它。

## 威霆显域 `lightning_domain`

> 「施用法术，将体内的『幽雷之力』散布开为一片领域，并维系一段时间。」
> 「凡是胆敢擅闯领域的外者，皆遭遍地电泳所吸而倍感沉重，且更易为电所伤；而施法者则增益有加，来去自如。」
> 「最妙的是，其攻击将更易穿甲。」「领域范围随技能等级（经验等级）而增长。」「不得在熔岩内施用。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:simple`，`cast_time` 80 刻，冷却 2000 刻（100 秒），初始耗蓝 8 |
| 蓄力期间可移动 | 否（读条期间锁颈锁尾，动画 `cast_magic_alt` → `magic_alt`） |
| 使用限制 | **眼睛处于熔岩中时禁用** |
| 等级 | 最高 5 级，`dragonsurvival:experience_levels` 经验等级升级：`10 / 20 / 30 / 40 / 50` |
| 定位 | 环形半径 `4 + 4 × (等级 - 1)` 格，`additional_abilities:annulus` 与 `additional_abilities:domain` 双选择器 |

**效果**：四段动作。

1. **蓄力预告**（`trigger_point` = `charging`，`trigger_rate` 10）：
   读条期间**每 10 刻**，在脚下半径 `4 + 4 × (等级 - 1)`、宽 2、高 4（向下延伸 4 格）的**环形**
   （`additional_abilities:annulus`）内的**非空气方块**上，迸出 10 颗 `minecraft:end_rod`（末地烛）粒子 ——
   这就是「遍地电泳」的视觉预告。
2. **敌方领域**（`additional_abilities:domain`，半径同上、圆柱、时长 600 刻 = 30 秒）：领域内的
   **非友方生物**（`targeting_mode` = `non_allies`，`is_harmful` = `true`）持续获得：
   - **重力 +0.6**（`generic.gravity`，`add_multiplied_total`）—— 即「倍感沉重」；
   - **受电系伤害 ×2**（`#dragonsurvival:is_electric`，如雷电、电龙吐息）；
   - **30% 概率**施加**折翼**（`dragonsurvival:broken_wings`）—— 无法飞行。
   以上三条均为**隐藏**效果（`is_hidden: true`），时长随领域每刻刷新。
3. **己方领域**（`additional_abilities:domain`，同参数）：领域内的**友方与自身**（`targeting_mode`
   = `allies_and_self`）持续获得：
   - **护甲穿透 +0.4**（`dragonsurvival:armor_ignore_chance`）—— 即「攻击更易穿甲」；
   - **力量 II + 迅捷 II + 急迫 II**（`amplifier` 1）—— 即「增益有加，来去自如」。
4. **方块的充电云**（`dragonsurvival:disc`，半径同上）：领域内的**非空气方块**上以 **30% 概率**
   留下 `dragonsurvival:area_cloud` 云（时长 600 刻）—— 云中生物获得**充能**（`dragonsurvival:charged`）
   与**发光**（`minecraft:glowing`），并伴随 `dragonsurvival:large_lightning` 粒子。

**用法提示**：这是一发**攻守兼备的范围领域**，把脚下周围划成「自家的地盘」。伤害不直接来自技能本身，
而是**放大环境**：敌方在领域中**重力翻倍、行动迟滞、吃雷伤翻倍、三成概率坠地**；己方则**力量、迅捷、
急迫加身、攻击穿甲**。**领域不可移动** —— 施法那一刻就地定住，30 秒后自行消散。配合雷电、电系吐息
或队友的电系攻击，收益最能体现。注意 **100 秒的冷却**与 **8 点初始耗蓝** 让它成为一场硬仗的起手式，
而非随手放的光环。

## 障目之息 `smoke_breath`

> 「喷吐大量烟气，蒙蔽敌人的双眼。」
> 「射程取决于年龄，施加的失明时间则取决于经验等级。」「也有些许伤害，但远远低于炽焰之息。」
> 「无法在水下或雨间使用。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:channeled`，`cast_time` 5 刻，冷却 20 刻 |
| 持续耗蓝 | 每刻 `0.02` |
| 使用限制 | **眼睛在水中时禁用**；**下雨 / 下雪时禁用** |

**效果**：锥形吐息，3 段动作：

1. 对锥形内的敌人造成火焰伤害（`0.5 × 档位`）并施加**失明 200 刻（10 秒）**；
2. 自身播放烟气呼吸粒子；
3. 留下烟气云（40 刻，云中 10% 概率施加 600 刻失明）。

**用法提示**：起手极快（`cast_time` 5 刻），是贴脸打断 + 致盲的短冷却手段。敌人被失明后退开就是收益。

## 火眼金睛 `piercing_eye`

> 「在熔岩里的生活使你练就了一双火眼金睛，让目光能穿过迷雾（免疫失明）。」
> 「当然，此效果不能免疫黑暗。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:passive` 被动 |
| 等级 | 无 `upgrade` 配置 → 固定 1 级，不能升级 |
| 效果 | 将 `minecraft:blindness` 的持续时间 **× 0**，即完全免疫失明 |

**用法提示**：**只免疫失明，不免疫黑暗**（Darkness）。洞穴龙的常驻被动之一。

## 草木皆兵 `natural_alies`

> 「你与自然共生共处、交感相融，竟拥有了让一草一木传递攻势的魔力。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:simple`，`cast_time` 40 刻，初始耗蓝 6 |
| 冷却 | 每级 `600 / 800 / 1000 / 1200` 刻（30 / 40 / 50 / 60 秒；线性 `base` 600、每级 +200） |
| 蓄力期间可移动 | 否（读条期间锁颈锁尾，动画 `cast_mass_buff` → `mass_buff`） |
| 使用限制 | **必须站在草木系方块上才能放**（`#dragonsurvival:speeds_up_forest_dragon`） |
| 等级 | 最高 4 级，`dragonsurvival:dragon_growth` 成长升级：成长值 `30 / 40 / 50 / 60` → 1 / 2 / 3 / 4 级（超出用 fallback `10`） |
| 定位 | 半径 8，`dragonsurvival:area` 范围选择器 |

**效果**：三段动作。

1. **蓄力预告**（`trigger_point` = `charging`，`trigger_rate` 10）：
   读条期间**每 10 刻**把半径 8 格内、属于 `#dragonsurvival:speeds_up_forest_dragon` 的**非空气方块**
   染上本模组的 `additional_abilities:glow` —— 绿色 `#0cb97f`、`alpha` 0.5、`display_type` = `simple_shader`，
   单次 40 刻。一草一木先亮起来，也是在给对方「倒计时」。
2. **结算**（读条完成时执行一次，即默认 `trigger_point`）：
   对半径 8 格内**所有非友方生物**（`targeting_mode` = `non_allies`）中
   **正踩在草木系方块上**的个体（`target_conditions` → `entity_properties.predicate.stepping_on`）——
   - 造成 `forest_dragon:natural_force`（自然之力）伤害，数值 = **目标最大生命值 × `0.05 × 技能等级`**
     （5 / 10 / 15 / 20%），再按默认表达式乘上施法者的「龙之技能伤害」属性；
   - 施加**缓慢 II + 虚弱 II**（`amplifier` 1），时长 `100 / 160 / 220 / 280` 刻（5 / 8 / 11 / 14 秒）；
   - 追加一条**隐藏的**伤害修正 `forest_dragon:natural_damage_increase`：对
     `#forest_dragon:is_forest_dragon`（森林龙法术）的**受伤倍率 ×2**，时长同上 —— 即描述里的「更易为森林龙法术所伤」。
3. **表现**：半径 8 格内的非空气方块上迸出 5 颗 `minecraft:egg_crack` 粒子。

**用法提示**：这是一发**「地形绑定」的范围减益**，判定挂在**目标脚下**的方块上，而**自己脚下**只决定
「能不能放得出来」（`usage_blocked`）。所以正确用法是：先把敌人拖到草皮、泥土、腐殖土、原木或木板地面上
（`#dragonsurvival:speeds_up_forest_dragon` = `#minecraft:dirt` + `#minecraft:logs` + `#minecraft:planks` +
`#minecraft:wooden_slabs` + `#dragonsurvival:is_grassy` + 草方块），再施法 —— 石头、沙子、水面、半空中
**一点伤害都吃不到**。给目标挂上 ×2 易伤后再补一口龙息，是这套连招的收益点。

> 随技能一并新增的还有伤害类型 `forest_dragon:natural_force`
> （`data/forest_dragon/damage_type/natural_force.json`）与龙种伤害标签
> `#forest_dragon:is_forest_dragon`（`data/forest_dragon/tags/damage_type/is_forest_dragon.json`，
> 内含 `dragonsurvival:forest_breath` / `dragonsurvival:spike` / 本伤害类型），
> 以及死亡留言键 `death.attack.forest_dragon.natural_force`。

## 光补作用 `photorepair`

> 「随着年龄渐长，森林龙逐渐与身上共生之植物愈发熟络，而生发出可以让它们附着在盔甲与爪牙之上 ——
> 利用『光合作用』修补工具的能力。」
> 「触发冷却随技能等级（成长阶段）而递减。」「如技能名所言，仅能在白日、户外、晴朗时方能生效。」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:passive` 被动 |
| 持续耗蓝 | 保留魔力 `1`（`continuous_mana_cost`，`type` = `reserved`） |
| 冷却 | 每级 `800 / 600 / 400` 刻（40 / 30 / 20 秒；线性 `base` 800、每级 −200） |
| 使用限制 | **无法看见天空时禁用**；**下雨 / 下雪时禁用**；**夜晚（12000~23999 刻）禁用** |
| 等级 | 最高 3 级，`dragonsurvival:dragon_growth` 成长升级：成长值 `30 / 40 / 50` → 1 / 2 / 3 级（超出用 fallback `10`） |

**效果**：单一动作 —— 对**自身**（`target_type` = `dragonsurvival:self`，`targeting_mode` = `allies_and_self`）
结算一次 `additional_abilities:durability`（耐久设置）：

- **装备槽 + 爪牙槽**（`slots` = `["equipment", "claws"]`）内的可损坏物品 **+1% 最大耐久**
  （`operation` = `add`、`unit` = `percent`、`percent_base` = `max_durability`）。

**用法提示**：这是一条**离线自动修补**的被动技能 —— 一个纯属「光合作用」设定的修装备手段。
**三段条件缺一不可**：必须**露天**（头顶见得到天）、**非雨雪**、**白日**（游戏内 0~11999 刻，
即天亮到日落）—— 这意味着**洞穴、水下、密林深处、夜晚与雨天全都失效**，是一条「向阳而生」的技能。
`reserved` 类持续耗蓝意味着它**常驻占着 1 点魔力上限**，不会把你抽干，但魔力总量会一直少 1。
`percent_base` 用的是**最大耐久**，所以越是皮糙肉厚的大件（钻石镐、下界合金甲）修得越多；
磨损速度超过每秒 1.25%（3 级时 `800 → 400` 刻的冷却）时它追不回来，正常使用则绰绰有余。
**注意**：耐久效果是**纯瞬时**结算，因此修多少是一次性写死的值，不存在「持续修补」的过程。

## 安身法 `fire_ring`

> 「保命之奇术也，就地施法，片刻过后，即以自身为圆心画出一道火圈并形成持续之阵势。」
> 「形成瞬间可短暂无敌，并把敌方击退至圈外。」「阵法可存续一段时间，随时步出再折返亦无妨。」
> 「阵法的范围随技能等级而增长。」「只能在地上使用，且不可立于水中。」

> 原创技能，灵感来自国产 3A 大作 **黑神话·悟空**。id 落在 `wing_kirin:` 命名空间的原因见
> [总览](#总览)下方的说明。

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:simple`，`cast_time` 20 刻，初始耗蓝 10（**不随等级增长**） |
| 冷却 | 每级 `1600 / 2000 / 2400 / 2800` 刻（80 / 100 / 120 / 140 秒；线性 `base` 1600、每级 +400） |
| 蓄力期间可移动 | 否（读条期间锁颈锁尾，动画 `cast_mass_buff` → `mass_buff`） |
| 使用限制 | **必须站在地面上**；**眼睛在水中时禁用**；**下雨 / 下雪时禁用**；**非翼麒麟龙种禁用** |
| 等级 | 最高 4 级，`dragonsurvival:dragon_growth` 成长升级：成长值 `40 / 50 / 60 / 70` → 1 / 2 / 3 / 4 级（超出用 fallback `10`） |
| 定位 | 环形 / 圆盘 / 圆柱 / 领域四种选择器协同，半径均为 `3 + 3 × (等级 - 1)` 格、高 10（向下延伸） |
| 音效 | 读条 `block.enchantment_table.use`，释放 `item.firecharge.use` |

**效果**：七段动作 —— 读条期间 1 段预告，释放瞬间 2 段即时结算，随后 4 段领域按 40 刻间隔反复作用。

1. **蓄力预告**（`trigger_point` = `charging`，`trigger_rate` 5）：
   读条期间**每 5 刻**，在脚下半径 `3 + 3 × (等级 - 1)`、宽 3、高 10（向下延伸）的**环形**
   （`additional_abilities:annulus`）内的**非空气方块**上，染上本模组的 `additional_abilities:glow`
   —— 金色 `#fbdc92`、`alpha` 0.8、`display_type` = `simple_shader`。这是「火圈」的视觉预告。
2. **形成瞬间 · 无敌与击退**（`dragonsurvival:disc`，半径同上）：
   - 对**友方与自身**（`targeting_mode` = `allies_and_self`）结算 `dragonsurvival:heal` **20% 最大生命**，
     并施加**抗性提升 V**（`amplifier` 4）40 刻 —— 即「短暂无敌」；
   - 对**非友方存活生物**（`non_allies` + `living_entity`）造成 **5 点** `dragonsurvival:burn`（燃烧）伤害，
     并以力 `-3.0` 朝施法者**反方向**（`towards_entity` 取负）推开 —— 即「击退至圈外」。
3. **阵法 · 点亮地面**（`additional_abilities:annulus`，同参数）：环形范围内的非空气方块**全部点燃**
   （`dragonsurvival:fire`，`ignite_probability` 1.0）—— 这就是描述里的「火圈」本体。
4. **阵法 · 友方增益**（`additional_abilities:domain`，圆柱、半径同上、**时长 400 刻 = 20 秒**、
   `apply_interval` 40）：领域内的**友方与自身**持续获得：
   - **恢复 II + 法力之源 II + 抗火 II + 迅捷 II + 力量 II + 急迫 II + 生命提升 II**（`amplifier` 2，100 刻，每 2 秒刷新）；
   - **燃烧时间 −1**（`generic.burning_time`，`add_value`）—— 即火中不掉血，300 刻；
   - **移除最多 5 个负面效果**（`effect_removal`，`categories` = `HARMFUL`）；
   - **受伤倍率 ×0.7**（`#wing_kirin:instant_invisibility_immunity`，60 刻）—— 即「短暂无敌」的延续；
   - **免疫冰冻**（`#is_freezing` 倍率 ×0，6 刻）；
   - **自身发金光**（`dragonsurvival:glow`，`#fbdc92`，60 刻）。
5. **阵法 · 敌方压制**（`additional_abilities:domain`，同参数）：领域内的**非友方存活生物**持续获得：
   - **点燃 60 刻**（`dragonsurvival:ignite`）；
   - **缓慢 I + 虚弱 I**（`amplifier` 1，60 刻）—— 即「寸步难行」；
   - **移除全部正面效果**（`effect_removal`，`categories` = `BENEFICIAL`）；
   - **自身发红光**（`#e81313`，60 刻）；
   - **受火系伤害 ×3**（`#minecraft:is_fire`，60 刻）。
6. **表现 · 火花**（`additional_abilities:domain`，同参数）：领域内的非空气方块上迸出 5 颗
   `minecraft:instant_effect` 粒子。

**用法提示**：这是一发**阵地型保命技能** —— 全技能链条的收益都围绕「**画一个圈、圈里我说了算**」。
起手需要 1 秒读条且**不能移动**，所以正确节奏是**预判伤害到来前一刻落阵**：阵法一成形（第 2 段）
就给全队一次 20% 治疗 + 抗性提升 V，并把身边敌人推开，随后 20 秒的领域持续给己方叠满七种增益、
每 2 秒清一次负面状态、受火系伤害只吃 70%，对敌方则反向压制（点燃 + 缓慢虚弱 + 清光增益 + 吃火伤害翻三倍）。
**四条限制让它的使用场合非常明确**：必须着地、不可在水中、不可在雨雪中、仅限翼麒麟 ——
所以它是**陆地阵地战**的答案，而不是随手的应急按钮。冷却 80~140 秒偏长，
更适合作「团战开团 / 硬抗一轮爆发」的底牌，而不是每波小怪都放一次。

> 「完成『见鬼去吧』挑战进度以解锁。」
> 「捂好耳朵，要打雷了！」

（`wing_kirin:dragonsurvival/projectile_data/explosion_arrow*` 与对应函数）驱动。

**用法提示**：长冷却（15 秒）、偏高耗蓝，作为一次爆发使用。解锁需要完成进度「见鬼去吧」（把下界恶魂的火球打回去）。

## 无所遁形 `entity_marker`

> 「完成『眼前一亮！』进度以解锁。」
> 「发现敌人位置！（标记敌人 +10 分）」

| 项 | 值 |
|---|---|
| 激活 | `dragonsurvival:passive` + 触发器 `dragonsurvival:on_key_pressed`，键位为**鼠标左键** |
| 等级 | 最高 2 级，`experience_points` 经验点升级（`50 / 100 / 200`，超出用 fallback `100`） |
| 解锁 | 需**已是翼麒麟**，且已获得进度 `husbandry/make_a_sign_glow`（「眼前一亮！」） |
| 定位 | 射程 200，`looking_at` 目标，`all_except_self` |

**效果**：按左键标记**视线正对着的那个生物**，使其发光（光源 id `wing_kirin:looking_at_marker`，

**用法提示**：这是「标记」类技能 —— 让点指到的敌人显形，而使其无法隐蔽。
**只标记单个目标**（视线命中的那一个），不是范围扫描。可以在技能界面手动禁用。

## 怎么把技能发给玩家

技能默认按上表的龙种标签发放。测试 / 手动授予用 DS 自带的指令：

```
/dragon-ability add <目标> <技能id>        # 授予
/dragon-ability remove <目标> <技能id>     # 移除
/dragon-ability refresh [<目标>]           # 刷新技能数据
```

龙种标签文件位置：

```
data/dragonsurvival/tags/dragonsurvival/dragon_ability/<龙种>.json
```

本模组对这些标签是**追加**（`"replace": false`），不会覆盖原版龙种的技能表。
