# 审查编号索引（F / T / C）

> 本文件是**开发文档**，不是源码注释的一部分。
> 它记录 Additional Abilities 在 2026-10 一轮代码审查中使用的编号含义，
> 供阅读历史提交、`plan/` 目录下的审查记录，或旧版本源码注释时查对。

## 为什么要单独建这份索引

`plan/` 目录被 `.gitignore` 忽略，不进入版本库。而源码注释里曾经直接引用
`F13`、`T12`、`复审 P1` 这类编号，这些编号一旦脱离审查报告就无法解读，
读者看到的只是一个孤立的代号。

整理后的源码注释**不再保留编号**：凡是编号承载的结论，都改写成自足的表述
（"为什么必须这样做"），因为契约应当能被独立读懂。编号本身则保留在这里，
以免历史提交与既有审查文档失去可追溯性。

## 编号体系

| 前缀 | 含义 |
| --- | --- |
| `F##` | 审查发现的**问题/事实**条目 |
| `T##` | 由某一发现派生出的**改进行动**（实施批次） |
| `C##` | 用户已确认的**决策**（无需再问） |
| `P1/P2/P3` | 优先级：P1 核心行为正确性、P2 生命周期与接口、P3 注释与整理 |
